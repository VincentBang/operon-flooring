# Operon Blog Generator Plan

## Purpose

Generate practical, local, trade-informed blog ideas that support SEO and quote conversion.

This is not an auto-publishing system.

The goal is to create high-quality article plans that can be reviewed before publication.

## Rules

- keep articles practical
- keep articles Sydney-relevant where appropriate
- no generic AI filler
- no keyword stuffing
- always include internal links
- always include a quote CTA

## Blog Workflow

1. choose a keyword with real intent
2. define the customer question
3. set the target reader
4. build an outline
5. link to one product page
6. link to one suburb or homepage quote page
7. include a CTA to quote

## Required Blog Fields

- title
- keyword
- intent
- target reader
- outline
- internal links
- CTA
- related product page
- related suburb page

## Quality Control

Do not publish unless the draft:

- answers a real customer question
- sounds trade-informed
- includes cost or process detail where useful
- moves readers toward the quote tool
