# Stage 5 Contractor Scorecard Plan

Date: 2026-06-04

Purpose: define scorecard fields before any contractor-facing system.

## Scorecard Metrics

- Response time
- Quote sent rate
- Quote acceptance rate
- Job completion rate
- Complaint count
- Defect/rework count
- Warranty issue count
- Photo proof completion
- Customer communication quality
- Operator trust rating

## Data Sources

- Lead events
- Status history
- Operator notes
- Customer feedback
- Project proof uploads
- Complaint/warranty records

## Scoring Principles

- Start manual.
- Show raw facts before composite scores.
- Avoid over-weighting small sample sizes.
- Keep operator override available.

## Non-Goals

- No public contractor rating.
- No contractor marketplace profile.
- No automated penalty logic.
- No customer-visible score.

## Gate

Do not use scorecards for automated allocation until enough job history exists.
