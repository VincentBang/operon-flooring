# Operon Flooring UI System

This file is the permanent UI reference for the Operon Flooring website.

## Spacing

- Use an 8px grid system.
- Section padding should generally sit between `60px` and `80px`.
- Internal card spacing should follow the same 8px rhythm.
- Keep whitespace generous and calm rather than dense.

## Typography

- `H1`: `36px` to `42px`
- `H2`: `24px` to `28px`
- Body text: `16px` to `18px`
- Maintain strong hierarchy and readable line length.
- Prefer simple, premium, highly legible typography.

## Colors

- Primary: `#1e3a8a`
- Text: `#111`
- Background: `#f8f9fb`
- Border: `#e5e7eb`

Use color sparingly. The interface should feel clean and controlled, not loud.

## Components

- Cards: `16px` to `24px` radius
- Buttons: large, `10px` radius
- Inputs: clean, minimal, easy to scan
- Keep form controls touch-friendly and mobile-safe

## Visual Rules

Never:

- add gradients
- add animations
- add shadows stronger than subtle
- add clutter

Always prefer:

- clean spacing
- simple card structures
- clear hierarchy
- premium restraint
- fast readability
