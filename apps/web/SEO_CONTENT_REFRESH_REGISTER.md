# Operon SEO Content Refresh Register

Source-of-truth status: working register for refreshing existing pages before creating unnecessary new pages.

## Refresh Priority Rules

Prioritize pages that already have:

- commercial intent
- internal links
- visible CTAs
- product or quote pathways
- crawl history
- likely user demand

Refresh before creating new pages when the existing asset can better satisfy the same intent.

## Refresh Checklist

For each page:

- H1 matches page intent.
- Title/meta/H1 are aligned.
- Primary CTA is visible.
- Secondary quote-review CTA exists where natural.
- Internal links support parent/sideways/downstream pathways.
- FAQ answers are useful and not truncated.
- Schema matches visible FAQ content.
- No generic filler or duplicated suburb copy.
- Mobile layout remains compact.
