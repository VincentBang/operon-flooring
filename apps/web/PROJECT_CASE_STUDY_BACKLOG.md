## Purpose

Real project pages should strengthen local SEO, trust, product confidence, and quote conversion. They must be based on genuine work or verified project details.

## Required Proof Before Publishing

Each project candidate needs:

- suburb
- property type
- flooring type
- product or range if known
- approximate project size if available
- preparation work
- installation constraints
- customer decision context
- timeline
- visual outcome
- before/after photos if available
- internal links to product, suburb, quote, and guide pages

## Scope Standard Case Study Fields

Every future case study should collect enough detail to show real scope clarity without inventing claims.

Capture:

- product definition: category, brand/range/colour, thickness and plank size if known
- area and measurement: measured area, room count and stair details if applicable
- installation scope: supply/install split, method, underlay/acoustic layer and furniture handling
- site and access: house/apartment, level, lift, parking/loading and strata restrictions if relevant
- risk and preparation: existing floor, removal/disposal, subfloor condition, levelling and moisture notes
- finishing/accessories: trims, scotia, skirting, stair nosing, door trimming and transitions
- commercial clarity: whether GST, exclusions, validity and variation conditions were clarified
- final confirmation: what was checked before the work was booked

Use these fields to show operational clarity, not to create long case-study pages.
