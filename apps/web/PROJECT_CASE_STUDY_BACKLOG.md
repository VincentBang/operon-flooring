## Required Proof Before Publishing

Each project candidate needs:

- suburb
- property type
- flooring type
- product or range if known
- approximate project size if available
- preparation work
- installation constraints
- customer decision context
- timeline
- visual outcome
- before/after photos if available
- internal links to product, suburb, quote, and guide pages
