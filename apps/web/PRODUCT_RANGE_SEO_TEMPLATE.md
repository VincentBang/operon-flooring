# Operon Product / Range SEO Page Template

Use this template only when the range data is strong enough to create a useful page. Do not create thin duplicate pages for every colour.

## Page Target

Example targets:
- Kronoswiss Aqua Stop laminate flooring Sydney
- Preference hybrid flooring Sydney
- Godfrey Hirst hybrid flooring quote Sydney
- Karndean hybrid flooring installation Sydney

## Required Sections

1. **Product/range overview**
   - Brand, range, product category and confirmed visible specifications.

2. **Best-use case**
   - The property types, rooms or project types where the range is a practical fit.

3. **Installation considerations**
   - Floating/direct-stick where relevant, subfloor expectations, trims, stairs, door clearance and preparation risks.

4. **Apartment/acoustic considerations**
   - Include only where relevant. Do not imply strata compliance without confirmed acoustic documentation.

5. **Quote risks**
   - Area basis, removal, disposal, underlay, floor preparation, stairs, trims, access and exclusions.

6. **Similar alternatives**
   - Link to comparable ranges or the parent category where exact alternatives are not yet selected.

7. **Existing quote CTA**
   - “Already have a quote for this product? Check what it includes.”
   - Link to `quote-review.html`.

8. **Start quote CTA**
   - “Start quote with this product/range.”
   - Link to `quote.html` with safe category/range parameters only when supported by the existing product-selection handoff.

9. **Internal links**
   - Parent category page, `products.html`, `quote.html`, `quote-review.html`, `floorplan.html`, and one or two relevant guides.

## Guardrails

- Do not invent supplier claims, warranties, acoustic compliance, waterproof claims or completed Operon projects.
- Do not expose internal costs, margins, labour rates or supplier rates.
- Do not make the page if the range has only a name and no useful confirmed product context.
- Do not duplicate the same page for every colour unless the colour has meaningful search demand and enough unique content.
