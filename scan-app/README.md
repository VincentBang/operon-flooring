# Operon Floor Scan App

Standalone manual room measurement app.

## Scope

This app measures rooms only. It does not price jobs and does not depend on the Operon quote project.

Phase 1 supports:

- manual polygon room drawing
- area and perimeter calculation
- multiple rooms
- confidence scoring
- structured JSON export
- mock quote-system JSON reader

## Run

```zsh
npm start
```

Then open:

```text
http://localhost:4173
```

## Test
