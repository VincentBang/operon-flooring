## Update Rules

- Record the exact production deployment date before measuring.
- Use Search Console last 14 days vs previous 14 days and last 28 days vs previous 28 days.
- Do not mark a test successful from impressions alone; look at ranking URL, CTR, clicks and conversion assists.
- If impressions rise and CTR is weak, test a clearer title/meta.
- If the wrong URL ranks, inspect internal anchors and page intent before changing title/meta again.
- If average position is still outside the top 30, prioritise content depth and internal links before aggressive CTR testing.
